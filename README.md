# CodeAlpha Cloud Computing Internship Tasks

## Overview

This repository contains all projects completed as part of the CodeAlpha Cloud Computing Internship Program.

The projects demonstrate concepts related to cloud computing, cybersecurity, data management, and artificial intelligence.

---

## Completed Tasks

### Task 1 – Data Redundancy Removal System

A cloud-based system that identifies and prevents duplicate data storage using SHA-256 hashing and database validation.

#### Features
- Duplicate File Detection
- SHA-256 Hash Validation
- SQLite Database Integration
- Upload History Tracking
- Cloud Storage Simulation
- Dashboard Analytics

---

### Task 2 – SQL Injection Detection & Data Leak Prevention System

A secure web application designed to protect sensitive information from SQL Injection attacks using encryption and multi-layer security mechanisms.

#### Features
- SQL Injection Detection
- AES Encrypted Credential Storage
- Capability Code Verification
- Double Layer Security Protocol
- Security Event Monitoring
- Authentication System

---

### Task 3 – AI Chatbot Assistant

A Generative AI-powered chatbot built using Flask and Google Gemini AI to provide intelligent real-time responses.

#### Features
- Google Gemini AI Integration
- Real-Time Responses
- Website-Based Chat Interface
- General Knowledge Support
- Programming Assistance
- Cloud Computing Guidance
