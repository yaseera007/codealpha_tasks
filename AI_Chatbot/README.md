# AI Chatbot Assistant

## Overview

AI Chatbot Assistant is a Generative AI-powered chatbot developed using Flask and Google Gemini AI. The chatbot provides instant responses to user queries and can answer general knowledge, programming, cloud computing, and technology-related questions.

## Features

- Generative AI Chatbot
- Google Gemini Integration
- Instant Responses
- Website-Based Chat Interface
- Intelligent Question Answering
- User-Friendly Design
- Real-Time Communication

## Technologies Used

- Python
- Flask
- Google Gemini AI
- HTML
- CSS
- JavaScript
